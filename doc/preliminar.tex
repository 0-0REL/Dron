\subsection{Componentes del cuadricóptero}
El dron cuenta con los siguientes componentes:
\begin{itemize}
	\item 4 Motores sin escobillas (BLDC)
	\item 4 Control de velocidad electrónico (ESC)
	\item 1 batería LiPo
	\item 1 Computadora de vuelo, cuenta con:
	\begin{itemize}
		\item IMU (acelerometro, giroscopio y magnetómetro)
		\item barómetro
	\end{itemize}
	\item 1 Chasis
	\item 2 Helices CW
	\item 2 Helices CCW
\end{itemize}
\subsection{Control del cuadricóptero}
Se puede linealizar el modelo del dron mediante la serie de Taylor \cite{powersQuadrotorKinematicsDynamics2015} mediante
\begin{equation}
	\label{eq:taylor}
	\dot{\mathbf{x}} = \left.\frac{\partial}{\partial \mathbf{x}} f(\mathbf{x}, \mathbf{u})\right|_{(\mathbf{x}_0, \mathbf{u}_0)} (\mathbf{x} - \mathbf{x_0})
	+
	\left.\frac{\partial}{\partial \mathbf{u}} f(\mathbf{x}, \mathbf{u})\right|_{(\mathbf{x}_0, \mathbf{u}_0)} (\mathbf{u} - \mathbf{u_0})
	=\mathbf{Ax + Bu} 
\end{equation}

\[\mathbf{x_0} = \mathbf{0}_{12\times1}\]
\[\mathbf{u_0} = \begin{bmatrix} mg & 0 & 0 & 0 \end{bmatrix}^T\]

Se puede convertir el espacio de estados a funciones de trasferencia mediante
\begin{equation}
	\label{eq:ss2tf}
	\mathbf{G(s)} = \mathbf{C} \left[s\mathbf{I - A}\right]^{-1} \mathbf{B + D}
\end{equation}

El controlador PD tine la siguiente estructura
\begin{equation}
	\label{eq:c_pd}
    PD(s) = K_P + K_D s = K_D(s+a)
\end{equation}
\[K_P = a K_D\]

El controlador PID tine la siguiente estructura
\begin{equation}
	\label{eq:c_pid}
    PID(s) = K_P + \frac{K_I}{s}+ K_D s = K_D\frac{(s+a)(s+b)}{s}
\end{equation}
\[K_I = abK_D\]
\[K_P= (a+b)K_D\]

Modelo Interno para entrada escalón \cite{dorfInternal2022}
\begin{equation}
	\label{eq:c_mi}
	\begin{bmatrix}
		\dot{\mathbf{e}}(t) \\
		\dot{\mathbf{z}}(t)
	\end{bmatrix}
	=
	\begin{bmatrix}
		0 & \mathbf{C} \\
		0 & \mathbf{A}
	\end{bmatrix}
	\begin{bmatrix}
		\mathbf{e}(t) \\
		\mathbf{z}(t)
	\end{bmatrix}
	+
	\begin{bmatrix}
		0 \\
		\mathbf{B}
	\end{bmatrix}
	\mathcal{W}(t)
\end{equation}
\[\mathbf{e}(t) = y(t) -r(r)\]
\[\mathbf{z}(t) = \dot{\mathbf{x}}(t)\]
\[\mathcal{W}(t) = \mathbf{-K_1 e(t) - K_2 z(t)}\]

\subsection{Procesamiento de sensores}
\subsubsection{IMU}
Se pueden estimar los ángulos de orientación roll y pitch mediante un filtro complementario \eqref{eq:filto_comp} para fusionar la información de 
giroscopio y acelerometros, sin embargo aunque es sencillo de implementar y de muy bajo costo computacional tiende a variar con rápidos movimientos.
\begin{equation}
	\label{eq:filto_comp}
	\theta = \alpha(\theta(k-1) + \omega_{gyro}T) + (1-\alpha)\theta_{acc}(k)
\end{equation}
\begin{gather}
	\phi_{acc} = \frac{acc_y}{\sqrt{acc_x^2 + acc_z^2}}\\
	\theta_{acc} = -\frac{acc_x}{\sqrt{acc_y^2+ acc_z^2}}
\end{gather}

Una mejor forma de obtener la orientación es mediante filtro Madgwick, este proporciona roll, pitch y yaw \cite{madgwickEstimation2011a}, este se basa en
un algoritmo de gradiente descendente. Aunque es mas costoso es más preciso con un rendimiento comparable a un filtro Kalman extendido \cite{cavalloExperimental2014}.
El algoritmo proporciona la orientación en cuaterniones, los cuales pueden ser convertidos a ángulos de Euler mediante.
\begin{gather}
	\phi = \operatorname{atan2}(2(q_0q_1 + q_2q_3), 1 - 2(q_1^2 + q_2^2))\\
	\theta = \operatorname{asin}(2(q_0q_2 - q_3q_1))\\
	\psi = \operatorname{atan2}(2(q_0q_3 + q_1q_2), 1 - 2(q_2^2 + q_3^2))
\end{gather}
\subsubsection{Barómetro}
La altura ortométrica \cite{grovesBarometric2013} se calcula con la información del barómetro mediante la siguiente ecuación
\begin{equation}
	\label{eq:baro}
	H_b = \frac{T_s}{k_T}\left(\frac{p_b}{p_s}^\frac{Rk_T}{g_0} -1\right)
\end{equation}
Donde:
\begin{description}
	\item[$R$] 287.1 J/kgK
	\item[$k_T$] 6.5$\times10^{-3}$ K/m
	\item[$g_0$] 9.80665 m/s²
	\item[$p_s$] 101.325 kPa
	\item[$T_s$] 288.15 K
\end{description}
